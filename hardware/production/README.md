# production

基板発注用のデータと部品表（BOM）を置きます。

- [`bom.csv`](bom.csv) : 部品表（v0.1）
- `gerber/` : ガーバーデータ（設計後に追加）

## 部品表 v0.1 の概要

- 価格は 2026-11-09 時点の秋月電子通商・Pololu の Web サイトの表示（税込）
- 「1 台あたり」はパック品を 1 個あたりに割った値。実際の購入はパック単位
- 状態: **確定** / **要確認**（品番や在庫に確認が必要） / **未定**

### 1 台あたりの費用（概算）

| 項目 | 金額 |
| --- | --- |
| NUCLEO-L432KC | 2,800 円 |
| MP6500 ×2（Pololu、1 USD = 150 円で概算、送料別） | 約 3,000 円 |
| その他の電子部品（秋月） | 約 1,100 円 |
| モータ ×2 | 0 円（提供品） |

| 未定: LiPo 電池、基板、PLA、O リング、ねじ | — |

### 要確認・未定の項目

- 抵抗 27 Ω 1/2 W（赤外 LED 駆動の Re）: 秋月で見つからない。1/4 W 56 Ω を 2 本並列（28 Ω）にする案
- ヒートシンク: 秋月のセット品は在庫僅少
- MP6500: 国内の取扱店が未確認。Pololu から直接購入する場合は送料がかかる
- LiPo 電池、O リング、ねじ、基板の費用
