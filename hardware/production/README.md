# production

基板発注用のデータと部品表（BOM）を置きます。

- [`bom.csv`](bom.csv) : 部品表（v0.1）
- `gerber/` : ガーバーデータ（設計後に追加）

## 部品表 v0.1 の概要

- 価格は 2026-11-09 時点の秋月電子通商・RobotShop の Web サイトの表示
- 「1 台あたり」はパック品を 1 個あたりに割った値。実際の購入はパック単位
- 部品は秋月で手に入るものの中で最も性能のよいものを選ぶ
- 部品の種類はできるだけ減らす（電子部品は 23 種類。抵抗 4 種類、コンデンサ 2 種類）
- 状態: **確定** / **要確認**（品番や在庫に確認が必要） / **未定**
