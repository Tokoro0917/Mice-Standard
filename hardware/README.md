# hardware

KiCad の回路図・基板データです。

| ディレクトリ | 内容 |
| --- | --- |
| `main-board/` | メイン基板の KiCad プロジェクト `mice-standard`（回路図 A3 1 枚 + 基板）。`mice-standard.pdf` は KiCad なしで見られる回路図 |
| `sensor-board/` | センサ基板の KiCad プロジェクト（赤外 LED + フォトトランジスタ 1 組）。1 台に 4 枚使い、メイン基板の J10〜J13 のスリットに差し込んではんだ付けする |
| `lib/` | 自作フットプリント `Mice-Standard.pretty`（センサのスリット・タブ、スライドスイッチ、圧電サウンダ） |
| `production/` | 発注用データ（ガーバー、BOM、部品配置）。リリースごとに更新 |

基板は役員がまとめて発注します。部員ははんだ付けの際に `production/` の BOM を参照してください。

## 基板設計 v0.2（配置まで、配線は未着手）

### メイン基板（68 × 100 mm、JLCPCB の 100 × 100 mm 以内、配置図 `main-board/placement.png`）

- モータの上に水平に載せる。前（センサ側）が上。車軸は前端から 55 mm
- 幅 68 mm: ホイールの上まで基板を伸ばした（ホイールの上端 47 mm < 基板の下面 48.5 mm）。ホイールの上（|X| 26〜33 mm、車軸の前後 ±23.5 mm）には部品を置かない（足が当たるため）
- 壁センサのスリットは KOGUMA-Mk4 と同じ考え方で配置（`docs/spec.md`「壁センサの配置」）
- 配置: 前端に壁センサのスリット 4 つ、中央に NUCLEO（下に背の低い抵抗）、左右の帯にモータのコネクタ・表示 LED・スイッチ・ブザー、後ろに MP6500 ×2 と電源。MP6500 は NUCLEO 本体（ピンソケットより前後に長い）と重ならない位置
- 取付穴 M3 ×4（3D プリントの台に固定）

### センサ基板（12 × 30 mm + 差し込み部 8.6 × 2.5 mm）

- メイン基板の下に垂れ下がる向きに差し込み、差し込み部の先をメイン基板の上面ではんだ付けする
- 表のパッド（LED A / K）はスリットの矢印側、裏のパッド（PT C / E）は反対側と合わせる
