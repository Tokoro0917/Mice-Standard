# hardware

KiCad の回路図・基板データです。

| ディレクトリ | 内容 |
| --- | --- |
| `main-board/` | KiCad プロジェクト `mice-standard`。回路図は **A3 1 枚**にメイン基板とセンサ基板（4 枚）の部品をすべて描いている。`mice-standard.pdf` は KiCad なしで見られる PDF |
| `sensor-board/` | センサ基板の KiCad プロジェクト（壁センサ 1 組分）。1 台に 4 枚使い、メイン基板のスリットに差し込んではんだ付けする |
| `lib/` | 標準機で使うシンボル・フットプリント・3D モデル |
| `production/` | 発注用データ（ガーバー、BOM、部品配置）。リリースごとに更新 |

基板は役員がまとめて発注します。部員ははんだ付けの際に `production/` の BOM を参照してください。

## 回路図 v0.1 について

- KiCad 7 形式で作成。KiCad 8 以降（10 を含む）で開くと新しい形式に自動変換される
- フットプリントは未設定（基板設計の段階で割り当てる）
- MP6500 のピンの並びは確認済み（`docs/spec.md`「モータドライバ（MP6500）の接続」）
- 要確認: モータ線と XH コネクタのピン対応
